## 2024-03-01 - Optimizing Scroll Animations with IntersectionObserver
**Learning:** The codebase previously used a synchronous scroll event listener (`window.addEventListener('scroll', revealOnScroll)`) to handle animations for elements with the `.scroll-reveal` class. This approach constantly queries the DOM (`document.querySelectorAll('.scroll-reveal')`) and calculates bounding client rects on every scroll event, which causes layout thrashing and unnecessary main thread overhead, even if no such elements exist on the page.
**Action:** Replace synchronous scroll event listeners with an `IntersectionObserver`. Include a guard clause to exit early if no target elements are found. Configure the observer with a `rootMargin` to trigger animations at the desired scroll depth, add the active class when intersecting, and then immediately unobserve the element to save resources.
