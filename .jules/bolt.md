## 2023-10-27 - Intersection Observer for Scroll Effects
**Learning:** The existing scroll reveal logic (`revealOnScroll`) attaches a synchronous callback to the window `scroll` event. This callback calls `getBoundingClientRect()` on multiple elements, forcing the browser to perform expensive layout recalculations (layout thrashing) on the main thread during every scroll event, leading to jank and degraded performance.
**Action:** Replace synchronous `scroll` event listeners that check element positions with `IntersectionObserver`. `IntersectionObserver` handles visibility calculations asynchronously off the main thread. Always include a guard clause (e.g., `if (reveals.length === 0) return;`) before initializing the observer to avoid creating unused observers. When setting up the observer callback, account for elements that might already be scrolled past (e.g., on page reload) by checking `entry.boundingClientRect.top < 0` and applying the active state immediately.
