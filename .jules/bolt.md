## 2024-08-17 - Continuous Layout Thrashing from Empty NodeLists
**Learning:** The previous implementation used `window.addEventListener('scroll', revealOnScroll)` which continuously queried `document.querySelectorAll('.scroll-reveal')` and forced synchronous layout by calling `getBoundingClientRect()` on every scroll tick. In this static frontend architecture where `scroll-reveal` is defined in CSS but not currently used in the DOM, this resulted in continuous, unnecessary layout thrashing and main thread blocking during scrolling, as the empty NodeList check was missing.
**Action:** Replace synchronous `scroll` event listeners with `IntersectionObserver` containing early guard clauses (`if (elements.length === 0) return;`) to prevent overhead and layout thrashing, especially in architectures where CSS classes might be defined but not actively utilized.
