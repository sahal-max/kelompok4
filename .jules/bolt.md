## 2024-08-15 - Scroll Animation Layout Thrashing
**Learning:** The `.scroll-reveal` logic in `index.html` used `window.addEventListener('scroll')` and called `getBoundingClientRect()` on every scroll event for every matched element. This causes layout thrashing (synchronous layout recalculation) and blocks the main thread on an otherwise static site. Additionally, negative root margins in IntersectionObservers need special handling (checking `boundingClientRect.top < 0`) to correctly initialize elements that are already scrolled above the viewport, such as on page reload.
**Action:** Always prefer `IntersectionObserver` for scroll-based visibility checks over synchronous scroll event listeners. Ensure guard clauses and `boundingClientRect.top` checks are included for robustness with negative root margins.
