## 2024-05-24 - Layout Thrashing in Scroll Listeners\n**Learning:** The previous implementation used a `scroll` event listener that called `getBoundingClientRect()` on every single tick. This is a classic anti-pattern that forces synchronous layout (layout thrashing) and causes severe main thread blocking, particularly noticeable on mobile devices during fast scrolling. Replacing it with `IntersectionObserver` offloads visibility calculation to the browser.\n**Action:** Always prefer `IntersectionObserver` over bound `scroll` event listeners for elements whose visual state depends on viewport intersection.
