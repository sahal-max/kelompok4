## 2024-03-24 - Unnecessary Scroll Event Listeners for Non-existent Elements
**Learning:** In this project, `index.html` contained a `scroll` event listener that fired continuously and triggered forced synchronous layouts via `getBoundingClientRect().top` to check for `.scroll-reveal` elements, even though there were exactly zero elements using this class in the document. This is a severe performance anti-pattern (blocking the main thread for no reason).
**Action:** Always check if elements exist before initializing listeners that query the DOM on high-frequency events (like scroll or resize). Replace scroll listeners with `IntersectionObserver` paired with an early return guard clause (`if (elements.length === 0) return`) to completely bypass initialization when the target elements are absent.
