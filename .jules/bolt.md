## 2024-05-24 - Unused Scroll Animations Triggering Unnecessary Events
**Learning:** In a single-page HTML application, a `scroll` event listener bound to `window` for animation elements (like `.scroll-reveal`) will continuously fire on every scroll, *even if there are no elements on the page that use that class*. This causes unnecessary synchronous layout calculations (like `getBoundingClientRect()`) which degrades scrolling performance, even on views that don't need the animation.
**Action:** When implementing scroll-based reveal animations, always use `IntersectionObserver` instead of raw scroll event listeners. Ensure there is a guard clause (e.g., `if (elements.length === 0) return;`) so the observer isn't needlessly instantiated on pages or states where it's not used, and remember to `unobserve()` elements after they've been animated.
