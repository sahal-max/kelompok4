## 2024-08-24 - Unused Scroll Reveal Class Causes Scroll Thrashing
**Learning:** The `.scroll-reveal` class was defined in the CSS and had a JS handler (`revealOnScroll`) bound to the window `scroll` event. This handler executed `querySelectorAll` and DOM rect calculations on every single scroll tick, even though there were exactly ZERO elements in the HTML actually using the `.scroll-reveal` class. This means the app was paying a constant scroll performance tax for an unused feature.
**Action:** Always add a guard clause (`if (elements.length > 0)`) before setting up scroll listeners or IntersectionObservers. Replace expensive `scroll` event listeners with `IntersectionObserver` whenever possible to offload intersection checks to the browser engine, avoiding main thread blocking.
