## 2025-01-28 - IntersectionObserver Page Reload Edge Case
**Learning:** When using `IntersectionObserver` to trigger scroll animations (e.g., adding an `.active` class when elements scroll into view), elements that are already scrolled *above* the viewport (which can happen on a page reload that preserves scroll position) may not trigger an `isIntersecting` event initially because they are already completely out of the root margin boundaries. This codebase requires elements above the viewport to also have the `.active` class so they aren't hidden when the user scrolls back up.
**Action:** When replacing scroll listeners with `IntersectionObserver` in this codebase, ensure the observer callback includes a check for `entry.boundingClientRect.top < 0` (or similar logic depending on root margin) alongside `entry.isIntersecting` to correctly handle elements that have already been scrolled past.
