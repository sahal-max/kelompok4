## 2024-05-23 - Expensive scroll listener for unused elements
**Learning:** Found a scroll event listener in `index.html` that queried the DOM (`querySelectorAll`) and calculated bounding client rects on every single scroll frame for elements with the class `.scroll-reveal`, despite no elements in the HTML actually possessing this class. This is a severe anti-pattern for performance, causing main thread blocking for nothing.
**Action:** Replaced the unthrottled `scroll` event with an `IntersectionObserver`. Added a guard clause `if (reveals.length > 0)` to prevent initializing the observer entirely if the target elements don't exist in the DOM, eliminating the overhead completely for the current static page structure while keeping the logic available if elements are added later.
